================================================================================
编译管道详解
================================================================================

输入 C 源文件
    ↓
【词法分析】- 由 Flex 执行
  ├─ 识别关键字、运算符、标识符、字面值
  ├─ 记录 token 和行号
  └─ 输出：Token 列表
    ↓
【语法分析】- 由 Bison 执行
  ├─ 按照语法规则解析 token 流
  ├─ 构建抽象语法树（AST）
  └─ 输出：树形 AST
    ↓
【语义分析】- 由 C 代码执行
  ├─ 建立符号表
  ├─ 检查变量声明和使用
  └─ 输出：符号表
    ↓
【中间代码生成】- 由 C 代码执行
  ├─ 根据 AST 生成四元式
  ├─ 管理临时变量和标签
  └─ 输出：四元式列表
    ↓
编译完成！

================================================================================
常见问题快速解答
================================================================================

Q1：如何添加新功能？
A1：修改相应的文件：
   - 词法：修改 src/lexer.l
   - 语法：修改 src/parser.y
   - 代码生成：修改 src/codegen.c
   然后重新编译

Q2：如何处理错误？
A2：编译器会输出错误信息，包括：
   - 行号
   - 错误类型（语法错误、语义错误）
   - 错误描述

Q3：四元式是什么？
A3：四元式是一种中间代码表示：
   (op, arg1, arg2, result)
   例如：(+, x, 5, t0) 表示 t0 = x + 5

Q4：如何在 Linux 上使用？
A4：使用 Makefile：
   make           # 编译
   make clean     # 清理
   make rebuild   # 重新编译

Q5：能支持浮点数吗？
A5：当前不支持，但可以扩展。需要修改：
   - 添加 float/double 关键字（lexer.l）
   - 添加新的类型规则（parser.y）
   - 更新所有相关代码
