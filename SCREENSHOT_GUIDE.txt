【截图内容】

【关键内容展示】

  ───────────────────────────────────────────
  1    KEYWORD_INT       int            2
  2    IDENTIFIER        a              2
  3    SEMI              ;              2
  ...

【演示说明】
这部分展示了词法分析的结果，证明了：
✓ 正确识别关键字（int, if, else, while, for, scanf, printf）
✓ 正确识别运算符（=, +, -, *, /, %, ^, ==, !=, <, >, <=, >=, &&, ||, !）
✓ 正确识别标识符和数字字面值
✓ 正确追踪源代码行号

================================================================================

保存为 test\error2.c，运行：

================================================================================
9. 截图技巧
================================================================================

【Windows 系统】
✓ 使用 Win+Shift+S 进行截图
✓ 或右键 > 查看器 > 截图
✓ 或 print screen 键全屏截图
✓ 使用 Windows Terminal 可以获得更清晰的输出

【保存编译输出到文件】
运行以下命令：
  .\compiler.exe test\test1.c > output\test1_output.txt 2>&1

然后用文本编辑器打开该文件，全选并截图。

【使用终端的滚动缓冲】
在 PowerShell 或 CMD 中，可以向上滚动查看之前的输出，
通过调整窗口大小和滚动，可以显示完整的输出内容。

================================================================================
10. 输出文件位置
================================================================================

编译生成的文件：
  - compiler.exe : 可执行文件
  - obj/ : 目标文件目录
  - src/lex.yy.c : 生成的词法分析器
  - src/y.tab.c : 生成的语法分析器
  - src/y.tab.h : 生成的语法分析器头文件

运行输出：
  - 可以保存到 output/ 目录中
  - 默认输出到控制台
