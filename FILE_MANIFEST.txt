详细文件说明
================================================================================

【头文件】(include/)

1. ast.h (70+ 行)
   用途：定义抽象语法树的节点类型、操作类型、数据类型和节点结构
   关键内容：
   - enum NodeType：18 种节点类型
   - enum OpType：15 种运算符类型
   - struct ASTNode：动态树节点结构
   - 函数声明：节点创建、操作、析构函数

2. symbol_table.h (40+ 行)
   用途：定义符号表数据结构和操作函数
   关键内容：
   - struct Symbol：符号记录结构
   - struct SymbolTable：符号表管理结构
   - 函数声明：查找、插入、输出函数

3. codegen.h (40+ 行)
   用途：定义中间代码生成的数据结构和函数
   关键内容：
   - struct Quadruple：四元式结构
   - struct CodeGenerator：中间代码生成器
   - 函数声明：代码生成相关函数

4. lexer.h (15+ 行)
   用途：词法分析辅助定义和 extern 声明
   关键内容：
   - struct TokenRecord：Token 记录结构
   - extern 声明：extern 变量和函数

【源代码】(src/)

1. lexer.l (80+ 行)
   用途：Flex 词法分析器定义
   关键内容：
   - 26 个关键字识别规则
   - 15 个运算符识别规则
   - 标识符、数字、字符串识别规则
   - 注释支持
   - 行号跟踪

2. parser.y (330+ 行)
   用途：Bison 语法分析器定义，完整的 C 语法规则
   关键内容：
   - %union 定义：语义值类型
   - %token 声明：所有 token 类型
   - %type 声明：所有非终结符类型
   - 完整的语法规则：
     * 程序结构（program）
     * 声明列表（decl_list）
     * 语句列表（stmt_list）
     * 各种语句类型
     * 表达式和优先级
   - yyerror 错误处理

3. ast.c (250+ 行)
   用途：实现抽象语法树的所有操作
   关键内容：
   - createNode()：创建基础节点
   - createNumNode()：创建数字节点
   - createIdNode()：创建标识符节点
   - createBinOpNode()：创建二元运算节点
   - createUnOpNode()：创建一元运算节点
   - addChild()：添加子节点（动态数组管理）
   - freeAST()：递归释放树
   - printAST()：格式化输出树结构

4. symbol_table.c (80+ 行)
   用途：实现符号表的查询和管理
   关键内容：
   - createSymbolTable()：初始化符号表
   - insertSymbol()：插入符号并检查重定义
   - lookupSymbol()：查询符号
   - isSymbolDefined()：检查是否已定义
   - printSymbolTable()：格式化输出符号表

5. codegen.c (150+ 行)
   用途：实现中间代码生成
   关键内容：
   - createCodeGenerator()：初始化代码生成器
   - genCode()：生成四元式
   - getTempVar()：分配临时变量
   - getLabel()：分配标签
   - getOpString()：运算符转字符串
   - generateIntermediateCode()：递归生成语句代码
   - generateIntermediateCodeExpr()：生成表达式代码
   - printIntermediateCode()：格式化输出中间代码

6. main.c (80+ 行)
   用途：主函数，编译管道的总控制
   关键内容：
   - 命令行参数处理
   - 文件打开和关闭
   - 编译各阶段的调用
   - 错误处理
   - 内存清理

【FAQ】

Q：项目能在 Linux 上运行吗？
A：是的，只需使用 Makefile：make

Q：如何添加新的测试用例？
A：在 test/ 目录下创建新的 .c 文件，运行 compiler.exe <filename>

Q：如何修改语法规则？
A：修改 src/parser.y 文件，然后重新编译

Q：如何扩展支持的数据类型？
A：在 include/ 的相关头文件中添加新类型，更新 lexer.l 和 parser.y
