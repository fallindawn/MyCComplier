1. 功能概述
--------

在原有编译器仅支持 int 类型的基础上，扩展了编译器对多种 C 语言
数据类型的识别和支持。现在编译器可以识别和处理以下数据类型：

2. 新增支持的数据类型
--------

【基本数据类型】
✓ int          - 整数类型
✓ short        - 短整数类型
✓ long         - 长整数类型  
✓ long long    - 长长整数类型
✓ float        - 单精度浮点数
✓ double       - 双精度浮点数
✓ char         - 字符类型
✓ bool         - 布尔类型
✓ void         - 空类型

【无符号数据类型】
✓ unsigned int         - 无符号整数
✓ unsigned short       - 无符号短整数
✓ unsigned long        - 无符号长整数
✓ unsigned long long   - 无符号长长整数
✓ unsigned char        - 无符号字符
✓ unsigned float       - 无符号浮点数（扩展）
✓ unsigned double      - 无符号双精度浮点数（扩展）

3. 技术实现详节
--------

3.1 AST 头文件修改 (include/ast.h)
    - 扩展了 DataType 枚举，新增了17种数据类型常量
    - 新增类型覆盖基本类型和无符号类型组合
    
3.2 词法分析器修改 (src/lexer.l)
    - 新增了9个类型关键字的识别：float, double, char, short, long, 
      unsigned, bool, void
    - 增强了浮点数字面量识别：支持形如 3.14, 2.71828 的浮点数
    - 增加了字符字面量识别：支持 'A', 'B' 等单字符
    
3.3 语法分析器修改 (src/parser.y)
    - 在 token 声明中添加了新的类型关键字
    - 扩展了 decl 规则（声明规则），现在支持以下形式：
      * int ID;
      * float ID;
      * double ID;
      * char ID;
      * short ID;
      * long ID;
      * long long ID;
      * bool ID;
      * void ID;
      * unsigned int ID;
      * unsigned char ID;
      * unsigned short ID;
      * unsigned long ID;
      * unsigned long long ID;
      
3.4 符号表修改 (src/symbol_table.c)
    - 更新 printSymbolTable() 函数，支持显示新的数据类型
    - 添加了完整的类型到字符串的转换 switch 语句
    - 符号表输出现在可以准确显示变量的具体类型
    
3.5 其他增强
    - 支持在赋值语句中使用浮点数
    - 支持字符字面量的赋值
    - 完整的中间代码生成（四元式）

4. 编译流程改进
--------

【词法分析阶段】
- 现在可以正确识别所有新关键字
- 正确解析浮点字面量和字符字面量
- 详细的 Token 记录和打印

【语法分析阶段】
- 完整的声明语句解析
- 正确的无符号类型组合处理
- 错误检测和报告

【符号表构建】
- 准确记录变量的数据类型
- 完整的类型信息显示
- 支持类型检查的基础设施

【代码生成】
- 生成对应的四元式中间代码
- 保留后续类型检查和代码优化的接口

5. 使用示例
--------

test/test_types.c 文件演示了新增功能的使用：

    /* 整数类型声明 */
    int a;
    short b;
    long c;
    long long d;
    
    /* 浮点类型声明 */
    float x;
    double y;
    
    /* 字符类型 */
    char ch;
    
    /* 无符号类型 */
    unsigned int u_a;
    unsigned char u_ch;
    unsigned short u_b;
    unsigned long u_c;
    
    /* 布尔类型 */
    bool flag;
    
    /* 使用示例 */
    a = 100;
    x = 3.14;
    ch = 'A';

编译这个文件后，符号表会显示所有变量的具体类型。
