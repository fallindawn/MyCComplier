技术实现
================================================================================

【开发环境】
- 语言：C 语言
- 词法分析工具：Flex（lex 的现代实现）
- 语法分析工具：Bison（yacc 的现代实现）
- 编译器：GCC
- 操作系统：Windows (MinGW/Cygwin) / Linux

【项目结构】
```
myCComplier/
├── include/              # 头文件
│   ├── ast.h            # 抽象语法树定义
│   ├── symbol_table.h   # 符号表定义
│   ├── codegen.h        # 中间代码生成定义
│   └── lexer.h          # 词法分析器接口
├── src/                 # 源文件
│   ├── ast.c            # AST 实现
│   ├── symbol_table.c   # 符号表实现
│   ├── codegen.c        # 中间代码生成实现
│   ├── main.c           # 主程序
│   ├── lexer.l          # Flex 词法分析定义
│   └── parser.y         # Bison 语法分析定义
├── test/                # 测试用例
│   ├── test1.c          # 基本声明和赋值
│   ├── test2.c          # 循环和条件
│   ├── test3.c          # 算术运算
│   ├── test4.c          # 逻辑运算
│   └── test5.c          # for 循环
├── output/              # 编译输出目录
├── Makefile             # Linux/Mac 编译配置
├── build.ps1            # Windows PowerShell 编译脚本
├── build.bat            # Windows 批处理编译脚本
├── README.txt           # 项目说明（技术文档）
├── TUTORIAL.txt         # 完整教程和使用说明
├── DEMO_REPORT.txt      # 演示报告和功能说明
└── SCREENSHOT_GUIDE.txt # 截图获取指南
```

【核心数据结构】
1. AST 节点（ASTNode）
   - 节点类型：PROGRAM, DECL, STMT, EXPR, BINOP, UNOP 等
   - 子节点列表：支持任意数量的子节点
   - 数据字段：整数值、字符串、标识符、运算符类型

2. 符号表（SymbolTable）
   - 条目结构：名称、类型、声明行号
   - 功能：插入、查询、重复检查

3. 四元式（Quadruple）
   - 结构：操作符、操作数1、操作数2、结果
   - 支持临时变量和标签生成

【语法规则支持】
✓ 声明：int var;
✓ 赋值：var = expr;
✓ 条件：if (expr) stmt; if (expr) stmt else stmt;
✓ 循环：while (expr) stmt; for (init; cond; update) stmt;
✓ 输入输出：scanf(...); printf(...);
✓ 运算：算术、关系、逻辑、位运算
✓ 复合语句：{ stmt_list }

使用方法
================================================================================

【编译步骤】
1. 进入项目目录：cd myCComplier
2. 运行编译脚本：
   - Windows: powershell -ExecutionPolicy Bypass -File build.ps1
   - Linux/Mac: make
3. 生成 compiler.exe（Windows）或 compiler（Linux/Mac）

【运行编译器】
.\compiler.exe test\test1.c
.\compiler.exe test\test2.c
（其他测试文件类似）

【输出说明】
1. 词法分析结果：显示所有 token
2. 抽象语法树：树形显示程序结构
3. 符号表：显示所有声明的变量
4. 中间代码：显示四元式序列
