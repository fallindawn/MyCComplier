                 数据类型功能 - 快速参考指南

【支持的所有数据类型】

基本类型 (5 种):
  int         - 整数类型
  float       - 单精度浮点数
  double      - 双精度浮点数
  char        - 字符
  bool        - 布尔值
  void        - 空类型

整数类型修饰符 (4 种):
  short       - 短整数
  long        - 长整数
  long long   - 长长整数
  unsigned    - 无符号

无符号类型组合 (7 种):
  unsigned int
  unsigned short
  unsigned long
  unsigned long long
  unsigned char
  unsigned float (扩展)
  unsigned double (扩展)

【声明语法示例】

基本声明：
  int a;
  float x;
  double y;
  char ch;
  bool flag;
  void func;

整数类型声明：
  short s;
  long l;
  long long ll;

无符号类型声明：
  unsigned int u_a;
  unsigned short u_s;
  unsigned long u_l;
  unsigned long long u_ll;
  unsigned char u_ch;

【字面量支持】

整数字面量：
  a = 100;
  a = -50;
  a = 0;

浮点字面量：
  x = 3.14;
  y = 2.71828;
  x = -1.5;

字符字面量：
  ch = 'A';
  ch = 'X';
  ch = '0';

【使用示例】

```c
/* 多类型声明和使用 */
int a;
short b;
long c;
float x;
double y;
char ch;
unsigned int ui;
bool flag;

/* 赋值 */
a = 100;
b = 200;
c = 1000000;
x = 3.14;
y = 2.71828;
ch = 'A';
ui = 255;
flag = 1;

/* 表达式 */
a = a + 10;
x = x * 2.0;

/* 控制流 */
if (a > 50) {
    printf(1);
}

while (a < 200) {
    a = a + 1;
}
```

【编译和测试】

编译：
  mingw32-make

运行：
  ./compiler.exe test/test_types.c
  ./compiler.exe test/test_all_types.c

输出包含：
  - Lexical Analysis Results (词法分析结果)
  - Abstract Syntax Tree (抽象语法树)
  - Symbol Table (符号表 - 显示所有变量及其类型)
  - Intermediate Code (中间代码)
