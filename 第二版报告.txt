版本 2.0 - 数据类型功能增强版
发布日期：2025年12月19日

========================================================================
新增功能
========================================================================

【新增数据类型】
✓ 基本类型扩展：float, double, char, bool, void
✓ 整数修饰符：short, long, long long
✓ 无符号类型：unsigned int, unsigned short, unsigned long, 
              unsigned long long, unsigned char, unsigned float, 
              unsigned double

【新增语言特性】
✓ 浮点数字面量：3.14, 2.71828 等
✓ 字符字面量：'A', 'B', 'X' 等
✓ 类型声明：支持所有新增数据类型的变量声明
✓ 符号表增强：完整显示变量的数据类型

========================================================================
修改说明
========================================================================

文件修改列表：

1. include/ast.h
   - 修改内容：扩展 DataType 枚举
   - 新增 16 种类型常量
   - 保持 API 兼容性

2. src/lexer.l
   - 修改内容：新增关键字识别规则
   - 新增浮点数和字符字面量规则
   - 不影响现有 Token 识别

3. src/parser.y
   - 修改内容：扩展声明语法规则
   - 从 1 条规则扩展到 15 条规则
   - 保持表达式和语句语法不变

4. src/symbol_table.c
   - 修改内容：增强 printSymbolTable 函数
   - 完整的类型名称映射
   - 不改变符号表结构

========================================================================
已知问题与限制
========================================================================

1. 类型检查限制
   - 暂不支持隐式类型转换规则
   - 暂不支持类型兼容性检查

2. 功能限制
   - 暂不支持指针类型
   - 暂不支持数组类型
   - 暂不支持结构体和联合体

3. 语法限制
   - 不支持函数定义中的类型参数
   - 不支持 typedef 定义
